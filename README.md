# Closers Multi-Language Font
This is a modified Font with Japanese kana and Kanji support added to NAVER's Nanum font used by Closers Online

# Fonts Used

 - [Nanum Gothic - NAVER Corporation](https://fonts.google.com/specimen/Nanum+Gothic)
 - [Plex Sans - IBM](https://fonts.google.com/specimen/IBM+Plex+Sans+JP) 

# Disclaimer
This font is not at all associated or endorsed by NADDIC GAMES or NAVER please use it responsibly.

Certain Japanese characters may look strange as the japanese font was sized to best align with the source font.
